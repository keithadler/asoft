Applesoft BASIC for DOS

The ROM's bugs, on purpose. A 16-bit DOS binary, running here under DOSBox.

Console →

Just the ] prompt, the way the reference build starts. Prints no banner, because the binary it is checked against prints none.

IDE →

The windowed front end: menu bar, program listing, and a Machine pane showing zero page, the control stack and which bugs are switched on.

 
]LOAD MANDEL.BAS       banded by escape time, in four colours
]LOAD SIERP.BAS        Sierpinski, by the chaos game
]LOAD SPIRO.BAS        hypotrochoids
]LOAD MOIRE.BAS        interference, and the colour the display invents
]LOAD HGRDEMO.BAS      the colour rules themselves
]LOAD HGRSHAP.BAS      shape tables: DRAW, XDRAW, ROT, SCALE
]LOAD LORES.BAS        all sixteen lo-res colours
]LOAD SNAKE.BAS        a game: I J K M to steer, Q to quit
]RUN

In the IDE the Samples menu loads any of these in one pick.

Click the screen before typing, so it takes the keyboard. Lower case is fine: keywords and variable names fold to upper case, while what is inside quotes keeps the case you typed. In the IDE: F5 run, F9 list, F10 menus, Ctrl-Q quit.
